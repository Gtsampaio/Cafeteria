# Site de Cafeteria – HTML e CSS

Este repositório contém um site de cafeteria desenvolvido com HTML e CSS como atividade prática durante o curso do **Instituto PROA**. O projeto tem como objetivo praticar e aprimorar conhecimentos em desenvolvimento web, estruturação de conteúdo e estilização de páginas, sendo realizado para fins educacionais e de treinamento.

## Funcionalidades

- **Estrutura HTML:** Organização do conteúdo da página utilizando elementos HTML.
- **Estilização com CSS:** Aplicação de cores, fontes, espaçamentos e elementos visuais para criar uma interface agradável.
- **Apresentação da Cafeteria:** Exibição de informações sobre o estabelecimento e sua identidade visual.
- **Cardápio:** Organização e apresentação de produtos, como cafés e outras opções disponíveis.
- **Imagens:** Utilização de imagens para complementar o conteúdo e tornar a página mais atrativa.
- **Organização do Conteúdo:** Distribuição das informações em seções para facilitar a navegação e a leitura.

## Objetivo do Projeto

O projeto foi desenvolvido com finalidade educacional e de prática, visando consolidar conhecimentos fundamentais em HTML e CSS. Também busca desenvolver habilidades de organização, estruturação e estilização de páginas web por meio da criação de um site temático.

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo da página.
- **CSS3:** Estilização e apresentação visual dos elementos.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar o site.

## Aprendizados

Durante o desenvolvimento, são praticados conceitos de estrutura HTML, organização de conteúdo, seletores CSS, cores, tipografia, espaçamentos, posicionamento de elementos e construção de interfaces web.
